# Theory

This folder holds the project's claims: the manifesto and the hypotheses that follow from it. A theory page states a position and the questions it raises. It does not report results; those belong to an experiment, and decisions belong to a decision record.

- [manifesto.md](manifesto.md): the thesis (draft).

A hypothesis written here that an experiment later tests should be referenced by the experiment's `hypothesis` field. When an experiment contradicts a claim, change the claim in a new dated section and keep the old wording visible, rather than quietly rewriting it.
