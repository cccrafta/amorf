# Entity

A part of the [ontology](README.md). This page is the hub for the part: what it is, what the project currently holds about it, and the research filed under it. The studies and experiments stay the source; this page links to them.

## Definition

A node of knowledge: a subject (a building, a material, a technique, a maker) with its own metadata (title, type and so on) and media of any number of types: image, film, sound, 3D models, text. Examples: the Robie House by Frank Lloyd Wright; brick in vernacular Norwegian architecture. An entity is a subject, not a page; one entity can appear in many spaces and journeys. Data conventions: [../../../docs/conventions/entities.md](../../../docs/conventions/entities.md).

Architectural reading: Artifact: material, sonic and visual, not a data point.

## Open questions

- Which media types does an entity carry in the field, and which only when opened?
- How does a thumbnail that plays sound or shows a model behave among many others?
- How is an opened entity laid out, and how does a visitor move inside it and on to the next entity?
