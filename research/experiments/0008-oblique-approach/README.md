# EXP-0008: Oblique approach and staged reveal of an entity

Follows [STU-0001](../../studies/0001-promenade-architecturale/README.md). Independent of EXP-0006 and EXP-0007; it can run alongside them.

## Hypothesis

Choisy stressed that on the Acropolis the views are oblique and picturesque, not frontal, and that the layout lets one building take the walker's attention after another (STU-0001, notes on Choisy). In the field, every entity currently faces the visitor. If composition belongs to the arrangement relative to the moving visitor, an entity met at an angle and revealed in stages should hold attention longer than one presented whole.

It is wrong if recall and approaches do not rise, or if entities become harder to find.
